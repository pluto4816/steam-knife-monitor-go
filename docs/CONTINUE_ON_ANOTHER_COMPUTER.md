# 换电脑继续开发

## GitHub 中包含什么

代码、规格、回归测试、Android 夸克验收说明和局域网 HTTPS 启动脚本会随仓库同步。
本地 `steam-candidates.json`、`.sales-lan-test/`、数据库、访问密码和证书私钥不进入 Git。
`ca.crt`、`server.crt` 本身是公共证书，但无需放进源码仓库；新电脑应按其局域网 IP
生成新的测试证书。不要把 `ca.key`、`server.key`、`test-password` 或整个测试目录上传。

## 在新电脑恢复

1. 克隆或更新仓库，准备 Go、C 编译器（SQLite 的 CGO 依赖）、OpenSSL、Python 3 和 Bash。
2. 如需继续原账本，用 USB 或其他私密文件传输取走本机 `.sales-lan-test/` 中的
   `sales-migration-*.tar.gz`。该包包含 SQLite 一致性快照和已验证的候选目录，不包含密码、
   私钥或可执行文件。迁移包含个人账目，不上传 GitHub。
3. 解压到临时目录，将 `steam-candidates.json` 放在仓库根目录；创建 `.sales-lan-test/`
   并将 `sales-test.db` 放入其中。不要覆盖新电脑上已有的账本，先备份或使用空的新项目目录。
4. 运行 `go test ./...` 和 `go vet ./...`。
5. 用新电脑的局域网 IP 启动：

   ```bash
   bash scripts/sales-lan-test.sh 新电脑局域网IPv4
   ```

   设置新的至少 16 字符访问密码。使用新 IP 打开页面，重新安装新生成的测试 CA；旧密码
   不影响账本文件的恢复。此前的登录会话不会迁移。
6. 若新电脑使用 WSL 2，按 [手机 HTTPS 验收说明](SALES_MOBILE_ACCEPTANCE.md) 中的办法，
   用新电脑和新 WSL 的实际 IP 配置专用的 8443 转发与防火墙规则。不要照搬旧 IP。
7. 核对原持仓和历史记录，再继续开发。测试结束后移除不再使用的手机测试 CA。

若只要代码、不需要原账本，可跳过迁移包，直接以空账本运行。若没有候选目录，执行
`go run ./cmd/monitor -mode update-candidates` 重新生成；该操作会低频访问 ByMykel 和 SMIS，
首次生成耗时较长。2026-09-08 的生成结果为 426 项全部匹配；未来数量以新的验证结果为准。
